# Titanic Survival Prediction System

This project is a machine learning web application that predicts whether a passenger survived the Titanic disaster based on selected features.

## Features Used
- Pclass
- Sex
- Age
- Fare
- Embarked

## Machine Learning Algorithm
Logistic Regression

## Tech Stack
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
